# 仕事

私（長又）の「バイオリン初段」（~/violin-shodan、正本は dist/）の続き。公開後の検証 validation/check-deployment.mjs が落ちた。08「指の順番を自在に」（application94）の練習を選ぶ画面で、型⑥・「3と4」の形を選ぶと、390×740 で開始ボタンの下端が747px（条件は740以下）になる。

原因は前回の小修正で、形の選択ボタンの表記を「2と3がくっつく形」「1と2がくっつく形」「3と4がくっつく形」に長くしたこと。390px幅でボタンの中が2行に折り返して、背が伸びた。あわせて、見出し列の「練習する型」も「練習する／型」と2行に折れている。次のように直してほしい。

1. 形の選択ボタンの表示は「2と3」「1と2」「3と4」の短い表記にする（94番と19問の両方。aria-label には「2と3がくっつく形」などの長い名前を残す）。見出し列の名前は「指の形」のまま。
2. 練習を選ぶ画面の見出し列（「弦」「指の形」「練習する型」「問題」「進め方」など）は、390px幅でも320px幅でも1行に収める。収まらない見出しは、意味を変えずに短くするか、見出し列の幅を調整する（文字を小さくするのは禁止）。
3. この落ち方を手元で先に捕まえられるよう、validation/check-natural-layout.mjs に次を足す：390×740 で、application94 の全8型×3つの形、reading55 の全19問×3つの形について、開始ボタンの下端が740以下であること、見出し列と形の選択ボタンの文字が1行であること。条件を緩める変更はしない。
4. sw.js のキャッシュ名を上げ（頭は violin-shodan- のまま）、`node build-portable.mjs` で portable を作り直す。
