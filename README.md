# バイオリン初段

「弦しるべ」の改修版から分かれたアプリです。旧アプリは https://ngmt4amtk-web.github.io/genshirube/ に今のまま残し、このアプリは https://ngmt4amtk-web.github.io/violin-shodan/ で公開します。

バイオリン初心者が、譜面と指の間隔を見ながら音程を練習する静的Webアプリです。編集の正本は `dist/`。2026-10-16の小修正後は8章・40課題、すべて4分の4拍子です。廃止した8分音符課題・単独の指順課題・69番以外は既存IDを保持しています。

## 起動と編集

```sh
python3 -m http.server 8773 --bind 127.0.0.1 --directory dist
```

`app.mjs` は画面と進行、`content.mjs` と `repertoire.mjs` は課題、`score.mjs` はBravura字形の五線、`style.css` は配置です。新規の `intonation.mjs` がAnswer Tunerから移した目標Hz・範囲、`settings.mjs` が保存設定の正規化を担当します。`engine.mjs` は音高検出・音声再生・判定停止の状態を持ちます。本番依存は追加していません。

```sh
node build-portable.mjs
```

単一HTML版は `portable/バイオリン初段.html`。JSの構文と保存後の読み戻しも検査します。マイクはHTTPSまたはlocalhostで使用します。ファイル版のマイク可否はブラウザに依存します。キャッシュ名は `violin-shodan-v1-20261016a` です。

## 章と使い方

| 章 | 内容 |
| --- | --- |
| 01 | 開放弦・7つの弓の高さ・休符で移弦・8つの譜読み |
| 02 | 2と3をくっつける |
| 03 | はじめての音階 |
| 04 | 1と2をくっつける |
| 05 | 3と4をくっつける。全項目でA線の34lowも選択可能 |
| 06 | ハ長調・ト長調／1の指から始める音階 |
| 07 | 2の指の切替・3形比較・3の指の切替・2と3の同時切替 |
| 08 | 3つの指の形を選べる19の譜読み・指の順番を自在に |

02・04・05の章一覧は「この形をつかむ」「指を1本ずつ確認する」「色々な練習」の3行です。2行目は2・3・4の指の3項目、3行目は「4本の指を置いて、離していく」「全パターンの動きを練習する」「形を保って続ける」「開放弦を軸に往復する」「3音ずつ上り下り」の5項目へ進みます。練習からは元のサブ一覧、サブ一覧からは章一覧へ戻ります。灰色の説明は指の動きを短く示します。

「形を保って続ける」は①〜⑥が64番の6つ、⑦が旧「指の順番を変えてみる」の16音で、ランダムは7つから選びます。「全パターン」は改名前と同じ6組です。全項目で4弦、05ではA線のシ♭・ミ♭版も選べます。86番の課題は削除しました。94番は①〜⑧・ランダム・「①〜⑧を通す」で、選択見出しは共に「練習する型」です。指順とリズムは原本を保ちます。新規課題・原本にない指形の組合せにはページを表示しません。

「テンポで通す」は開始・再開時に4拍数えます。「1音ずつ」は即開始し、マイクなしでは手送りです。マイクをオンにすると「1音ずつ」になります。「1音ずつ」とマイク使用時の再開はカウントなしです。和音を含む「7つの弓の高さ」は単音判定の対象外で、マイクを表示しません。

マイクの既定はA=442・普通±8¢。設定でA=440、緩め±15¢、厳しめ±5¢を選べます。メーターは目標を中央とし、±50¢まで針を表示します。実際の差は符号つきの値と「高い・低い・ちょうど」で表示します。

合格は範囲内で320ms続いた時です。範囲外の音が650ms落ち着くたびに、目標Hzを1秒鳴らします。再生と350msの残響待ちの後、180msの無音を確認して判定を再開します。成功音の後もいったん弓を止めます。合格音は880/1320Hzの短い2音、全音を合格すると大きく長い2音です。

保存は `localStorage` の `violin-shodan-v1`。旧アプリの保存キーは読み込みも削除もしません。表示・音の設定と最後に選んだ課題・選択値だけです。廃止したeighth系・単独order系・connect69を含む不明なIDは、課題と選択値を開放弦の既定に戻します。「6段目」のような旧表記や範囲外の値も既定に戻し、有効な数値の選択は保ちます。廃止した開放弦の `mode=step` は4/4の「1音ずつ」へ移行します。練習記録・録音・外部送信・アナリティクスはありません。

## 検証

指定されたコマンドを使います。

```sh
node verify.mjs
node extension-check.mjs
node build-portable.mjs
python3 -m http.server 8773 --bind 127.0.0.1 --directory dist
node validation/check-natural-layout.mjs
node validation/check-ui.mjs
```

サーバーは画面検査の前に別ターミナルで起動します。改名・分岐前の実行記録は `validation/2026-10-15-results.json`。既存のスクリーンショットや `ui-results.json`、`natural-layout-results.json`、`unit-results.txt` は今回の画面確認の証拠ではありません。

`verify.mjs` は42検査です。ランダム1000種、全課題・弦・形・型の4/4とスラー0、共通メニュー、原本の指順、Answer Tuner数値、A基準と3段階、誤答後の状態、開始/再開の4カウント、保存キーの分離、廃止IDと古い保存値、3行と2つのサブ一覧、説明の重複、①〜⑦/⑧とランダム、元の一覧への戻り先、実際のアプリ進行をDOM・音声APIの代役で確認します。代役による検査は描画の検証ではありません。

`extension-check.mjs` は16検査です。既存教材の照合に加え、44.1/48kHzの合成波形390例（全形の目標と上下1オクターブ）が5¢以内、成功音/正しい音の周波数と再生長、画面検査スクリプトの構文、全幅でsafe areaを加えるCSS、旧アプリのキャッシュを触らないことを検査します。実楽器や室内雑音への精度を証明するものではありません。

画面検査は既存のPlaywright環境を使います。`check-natural-layout.mjs` に全40課題、全34low、①〜⑦、追加切替・新規課題の譜面検査を追加しました。`check-ui.mjs` に8章・3行と両サブ一覧の往復、①〜⑦/⑧の選択、旧保存値、safe areaを模した余白、44pxボタン、偽マイクの音名/高低/抑止、320×568で小節・次音・拍・停止・メーターが同時に見えること、200%文字、テンポの開始・再開の4カウントと1音ずつ・マイクの即再開、保存設定を追加しました。

ホーム画面起動時の上端は `.app-header`、通常画面の左右・下端は `.workspace` にsafe areaの余白を加えます。演奏画面は `.performance-viewport` の四辺に余白を加え、`box-sizing:border-box` で100svhの内側に収めます。

今回、サーバー起動とブラウザ検査は常設指示により実行していません。呼び出し側で実行してください。iPhone Safariと本物のバイオリンでの判定・音量・残響・可読性も未確認です。コミット・公開も呼び出し側の担当です。

2026-10-16の検査では、改修前の19問を固定した `validation/reading55-before.mjs` と形23を全問比較し、形12・34で弦・指・長さが保たれることと音高の差を確認します。小さな小節数表示の削除、69番の保存値の復帰、19問の形選択と音名・図・マイク目標の連動も検査します。`check-ui.mjs` の19問・3形の選択と表示の画面検査は呼び出し側で実行します。

## 移植元と調の結論

読み取り専用で参照した原本は `~/AnswerTuner/AnswerTuner/Core/IntonationMath.swift`、`TonalContext.swift`、`DrillTarget.swift`、`~/AnswerTuner/AnswerTuner/DrillState.swift` と、`AnswerTunerTests/IntonationMathTests.swift`・`AnswerTunerCoreTests.swift`・`ListenTests.swift` です。検査へ移した値は、12音程の旋律/和声差、21.506¢・23.460¢のコンマ、開放弦4本、レ長調VI度、ハ長調のミ、♭主音、増4/減5、異名同音64綴り、短調下行、基準周波数と合格範囲です。数値照合は0.1¢より厳しい許容差で通しています。

補助音と無音待ちは `~/fuyomi/docs/decisions.md` の2026-09-12節と `js/app.js`・`js/pitch.js` を参照しました。原本への変更はありません。

アプリの音律はAnswer Tunerの独奏・旋律です。23は開放弦を主音、12は短3度上、34は完全5度上、34lowはシ♭長調。音階は各音階の調、切替課題は音ごとの形の調です。reading55は各音の弦と選んだ指の形から調を決め、既存の音ごとの臨時記号表示を使います。既定の形23は改修前の全19問と同じ音高・弦・指・長さです。application94は選んだ弦・形の長調です。

今回の音列の旋律目標は、同じ綴りなら調を替えても変わりません。全音で確認しました。Aからその綴りまでの五度圏歩数に `1200 × log2(3/2) − 700 = 1.9550008654¢` を掛けた値と一致します。和声目標は調により変わりますが、アプリの判定には使いません。開放弦は専用関数の目標を使用します。
