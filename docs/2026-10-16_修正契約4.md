# 仕事

私（長又）の「バイオリン初段」（~/violin-shodan、正本は dist/）の続き。楽譜に出ている小節番号（各小節の左上などに出る小さな数字 1・2・3…）を、アプリのすべての楽譜から消してほしい。前回の小修正で消したのは見出し横の「N小節」などの文字表示で、本当に消したかったのはこの楽譜の上の番号だった。

1. dist/score.mjs で小節番号を描いている所を消す。今わかっているのは2か所：1小節ずつの描画（`<text x="12" y="159" …>${bar+1}</text>`、演奏画面の今の小節）と、連続した五線の描画（`<text x="${x+5}" y="19" …>${bar+1}</text>`、練習を選ぶ画面と全体の楽譜）。ほかにもあれば全部。SVG の aria-label の「N小節目」は読み上げ用なので残してよい。
2. 番号を消して空いた上の余白を詰めてよい。ただし音符・加線・指番号・弦の文字が切れないこと（今の検査どおり）。
3. 楽譜に小節番号の数字が描かれていないことを検査に足す（SVG の text 要素のうち、小節番号に当たるものが0）。
4. sw.js のキャッシュ名を上げ（頭は violin-shodan- のまま）、`node build-portable.mjs` で portable を作り直す。DESIGN.md の「2026-10-16 小修正」節に1行足す（楽譜の小節番号を消した、本人の指示）。

## 合格条件（機械判定可能）

1. `node verify.mjs` と `node extension-check.mjs` が exit 0（小節番号が無いことの検査を含む）。
2. `node build-portable.mjs` が exit 0。
3. `grep -n 'bar+1}</text>' dist/score.mjs` の結果が0件。
4. 画面の検証は私の側で回す。
