# 仕事

私（長又）は、改修した「弦しるべ」を別のアプリ「バイオリン初段」として、別のURL https://ngmt4amtk-web.github.io/violin-shodan/ に出す。旧アプリ https://ngmt4amtk-web.github.io/genshirube/ は今のまま残す。作業フォルダは ~/violin-shodan（~/genshirube-20261014 の改修版を丸ごと写したもの。正本は dist/）。次の4点をやってほしい。

1. アプリ名を「バイオリン初段」に変える。画面の見出し、<title>、manifest.webmanifest の name と short_name、apple-mobile-web-app-title など、利用者に見える「弦しるべ」を全部置き換える。portable 版の出力は portable/バイオリン初段.html にし、古い portable/弦しるべ.html は消す。README.md と DESIGN.md の冒頭は「バイオリン初段」とし、弦しるべから分かれたアプリであること（旧アプリは別URLで残す）を1〜2文で書く。DESIGN.md の過去の節に出てくる経緯としての「弦しるべ」は書き換えなくてよい。

2. 旧アプリと同じドメインに並ぶので、ぶつからないようにする。保存設定の localStorage キーを `violin-shodan-v1` にする（旧キー `genshirube-v1` は読まない・消さない）。sw.js のキャッシュ名を `violin-shodan-` で始まる名前にし、activate で消すのは `violin-shodan-` で始まる古いキャッシュだけにする。`genshirube-` のキャッシュには一切触れない。この2点を verify.mjs か extension-check.mjs で検査する。

3. 「テンポで通す」の再開を元に戻す。前回の改修で、一時停止からの再開がどのモードでもカウントなしになった（beginTransport(p.index,true)）。私の意図は「1音ずつ」とマイク使用時だけカウントなしで、テンポで通す時は旧版どおり再開でも4カウントを数える。validation/check-ui.mjs の「continuous mode counts four and resumes immediately」も、再開で4カウントを通る検査に直す。

4. 公開の準備。DEPLOYMENT.md を新しいURLとリポジトリ ngmt4amtk-web/violin-shodan に書き換える（gh-pages ブランチの / を配信、dist の中身だけを出す、手順は今のものを踏襲）。validation/check-deployment.mjs の公開先URLを新しいURLにする。dist/.nojekyll を置く。

## 触ってよい範囲

- ~/violin-shodan/dist/ の全ファイル
- ~/violin-shodan/README.md、DESIGN.md、DEPLOYMENT.md、verify.mjs、extension-check.mjs、build-portable.mjs、portable/、validation/

## 禁止

- git のコミット・push、ネットワークへのアクセス
- ~/genshirube-20261014 への書き込み
- docs/ 配下の編集
- 前回までに決めた仕様（章立て、課題、判定幅、音、メーター）を変えること

## 規約

- 既存の書き方に合わせ、上の4点に必要な所だけ直す。

## 合格条件（機械判定可能）

1. `node verify.mjs` と `node extension-check.mjs` が exit 0。上の2の検査と、テンポで通す時の再開が4カウントの状態を通る検査（単体で書けるなら）を含む。
2. `node build-portable.mjs` が exit 0 で、portable/バイオリン初段.html ができ、portable/弦しるべ.html が無い。
3. `grep -rn "弦しるべ" dist` の結果が0件。
4. `grep -rn "genshirube" dist` の結果は、sw.js で旧キャッシュに触れないことを示すコメント以外に無い（できれば0件）。

## 検証コマンド（このまま使え。別のツールを探すな）

```
cd ~/violin-shodan
node verify.mjs
node extension-check.mjs
node build-portable.mjs
bash -c 'grep -rn "弦しるべ" dist; grep -rn "genshirube" dist; ls portable'
```
