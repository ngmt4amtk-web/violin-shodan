# 仕事

私（長又）の「バイオリン初段」（~/violin-shodan、正本は dist/、公開 https://ngmt4amtk-web.github.io/violin-shodan/）のメニューを、iPhoneで使ってみた結果に合わせて組み直してほしい。対象は02「2と3をくっつける」・04「1と2をくっつける」・05「3と4をくっつける」の3章で、3つとも同じ構成にする（弦は今と同じく4本から選べ、05のA線のシ♭・ミ♭版も今のまま全項目で選べる）。

1. 章の一覧に出すのは次の3行だけにする。
   - この形をつかむ（今のまま）
   - 指を1本ずつ確認する（今の「指を1本ずつ足す」の名前を変える。押すと今と同じ「2の指を足す／3の指を足す／4の指を足す」の一覧へ移る）
   - 色々な練習（新しい親の行。押すと次の5つの一覧へ移る）
     1. 4本の指を置いて、離していく（今の「まとめて置いて、下る」の名前を変える。中身はそのまま）
     2. 全パターンの動きを練習する（今の「6組の指を往復する」の名前を変える。中身はそのまま）
     3. 形を保って続ける（下の2のとおり）
     4. 開放弦を軸に往復する（今のまま）
     5. 3音ずつ上り下り（今のまま）
   一覧から練習へ入って戻ると、入った元の一覧（サブ一覧）へ帰る。サブ一覧から戻ると章の一覧へ帰る。今の「指を1本ずつ足す」のサブ一覧と同じ動きにそろえる。

2. 「形を保って続ける」の選択肢を ①〜⑦ とランダムにする。①〜⑥＝今の64番の6段（指の順番とリズムは原本のまま）、⑦＝今の「指の順番を変えてみる」の内容（0・1・2・3、1・2・3・4、0・1・2・1、1・2・3・2）。単独の「指の順番を変えてみる」の項目は一覧から消す。ランダムは7つから選ぶ。「1段目」「練習する段」のような段の言葉は使わず、選択肢は「①」〜「⑦」「ランダム」、見出しは「練習する型」にする。

3. 「8分音符で確かめる」を全章から消す（86番もアプリから無くなる。それでよい）。

4. 08の「指の順番を、自在に」（94番）も表記をそろえる。選択肢は「①」〜「⑧」「ランダム」「①〜⑧を通す」、見出しは「練習する型」。中身は変えない。

5. 一覧の各行の下の灰色の説明を、その練習でやることに替える。今は02の6行が全部「2と3がくっつく形」で同じになっていて情報がない。同じ一覧の中で同じ説明が2回出ないこと。たとえを使わず、やることをそのまま短く書く（例：「0から4へ上って戻る」「4本を置いてから4・3・2・1と離す」）。章の形の名前は章の見出しにあるので行ごとには繰り返さない。

6. iPhoneでホーム画面から開くと、上の見出し（アイコン・「バイオリン初段」・設定ボタン）が時刻と電池の表示に重なる。index.html は viewport-fit=cover なので、見出しと各画面の上端・左右・下端に env(safe-area-inset-*) の余白を足し、見出しと設定ボタンが状態表示に重ならないようにする。演奏画面（.performance-viewport の100svh）も、上端と下端の余白を含めて1画面に収まるようにする。

7. 仕上げ。保存設定に、消した課題の id や古い段の値（eighth 系・単独の order 系・「段」の値など）が残っていても、落ちずに既定へ戻ること。sw.js のキャッシュ名を上げる（頭は violin-shodan- のまま、genshirube- には触れない）。`node build-portable.mjs` で portable/バイオリン初段.html を作り直す。DESIGN.md の「2026-10-15 改修」節の後に「2026-10-15 メニュー再編」の節を足し、上の決定を書く（本人の選択：親の行は「色々な練習」、「指を1本ずつ足す」は「指を1本ずつ確認する」へ改名、6組は名前だけ変えて中身は6組のまま、⑦は旧「指の順番を変えてみる」、アイコンの「弦」は変えない）。

## 合格条件（機械判定可能）

1. `node verify.mjs` と `node extension-check.mjs` が exit 0。次の検査を足したうえで通ること。
   - 02・04・05の章の一覧がちょうど「この形をつかむ」「指を1本ずつ確認する」「色々な練習」の3行で、2行目のサブ一覧が2・3・4の指の3つ、3行目のサブ一覧が上の順の5つ
   - 全章に「8分音符で確かめる」と単独の「指の順番を変えてみる」が無い
   - 「形を保って続ける」の選択肢が①〜⑦とランダム、⑦の音が旧「指の順番を変えてみる」と同じ。94番が①〜⑧とランダムと「①〜⑧を通す」
   - アプリ全体の画面文言に「段目」「練習する段」が無い
   - 同じ一覧の中で灰色の説明が重複しない
   - 古い保存設定（消した id、段の値）で初期化しても落ちない
2. `node build-portable.mjs` が exit 0。
3. 画面の検証（validation/check-ui.mjs と validation/check-natural-layout.mjs）は私の側で回す。新しい一覧の動き（3行・2つのサブ一覧・戻り先・①〜⑦の選択）を check-ui.mjs に足しておくこと。サーバーやブラウザは起動しなくてよい。
