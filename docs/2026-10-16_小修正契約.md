# 仕事

私（長又）の「バイオリン初段」（~/violin-shodan、正本は dist/、公開 https://ngmt4amtk-web.github.io/violin-shodan/）に、次の3つの直しを入れてほしい。

1. 小さな小節数の表示を消す。消すのは次の3つの小さな表示だけ。
   - 練習を選ぶ画面で、楽譜の見出し（「この練習の楽譜」「はじめの6小節」）の横に出る「N小節」
   - 演奏画面の右上の「N 小節目」（#barLabel）
   - 全体の楽譜の「全N小節 · 今 N小節目」（#scorePageLabel）
   見出しそのもの、「全N小節を見る」のボタン、全体の楽譜の見出し、説明文の「4小節です」などは残す。表示を消して空いた所は詰めて、配置が崩れないようにする。

2. 07「4本の弦を、つなぐ」（connect69、69番）を消す。07は残り4つ（2の指の場所を切り替える／変わる指と変わらない指／3の指を上げ下げする／2と3を一緒に動かす）になる。保存設定に connect69 が残っていても落ちずに既定へ戻ること。

3. 08「読んで弾く・19の問題」（reading55）
   - ページ番号を消す。課題の page を null にし、問題の選択肢「その1 · p.72」の「 · p.72」を外す。
   - 指の形を選べるようにする。選択肢は「2と3がくっつく形」（既定・教本のまま）／「1と2がくっつく形」／「3と4がくっつく形」の3つで、94番（application94）の形の選び方と同じ部品・同じ言葉にそろえる。どの問題も、各音の弦と指番号は原本のまま、音の高さだけ選んだ形で作る。2と3を選んだ時の音は、今の19問と完全に同じであること。楽譜の♯・♭・♮、音名、指の形の図、マイクの目標の高さ（調は前回までと同じ規則で、音ごとにその形と弦から決める）も選んだ形に合わせて変わる。説明文の「音は問題ごとに決まっています」は、形を選べることが分かる文に直す。
   - 弦の選択は付けない（問題ごとに弦が決まっているため）。

最後に sw.js のキャッシュ名を上げ（頭は violin-shodan- のまま）、`node build-portable.mjs` で portable/バイオリン初段.html を作り直し、DESIGN.md に「2026-10-16 小修正」の短い節を足す（本人の選択：消す小節数は小さな表示だけ、69番は06のト長調2オクターヴで同じ形の切り替えを練習できるので削除、19問は指の形を選べる）。
